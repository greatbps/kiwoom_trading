# CHoCH 등급 재교정 보고서

> **문서 목적**: 현재 A/B/C 등급 체계가 실제 기대값을 분리하는지 검증하고, 재설계 방향을 결정한다.  
> **데이터**: SMC 진입 26건 (2026-01 ~ 2026-04), 전체 113건  
> **최종 갱신**: 2026-07-05 | ruleset_version v1.3.1-final

---

## ⚠️ 결론 먼저

**현재 등급 체계 자체는 틀리지 않았다. A > B 분리는 유효하다.  
그러나 등급보다 시장 레짐이 더 강력한 결정 요인이다.  
B급 진입은 즉시 비활성화 권고. A급은 시장 레짐 게이트를 추가해야 한다.**

## 1. 현재 CHoCH 등급 체계

### 1.1 점수 항목

실제 코드(`analyzers/smc/smc_signals.py`, `evaluate_choch_grade()`):

| 항목 | 최대 점수 | 조건 |
|------|---------|------|
| HTF 30분봉 추세 일치 | +15 | CHoCH 방향과 HTF 추세 일치 |
| Liquidity Sweep (방향 일치) | +25 | Sweep 방향 = CHoCH 방향 |
| Liquidity Sweep (방향 불일치) | +10 | Sweep 있으나 방향 다름 |
| 강한 Order Block (OB) | +20 | OB 가격 범위 기준 충족 |
| 약한 Order Block | +10 | OB 있으나 약함 |
| Squeeze 수축 + 변동성 수축 | +15 | Squeeze ON + ATR 수축 |
| 일반 변동성 수축 | +15 | ATR 수축 (Squeeze 없이) |
| VWAP 위 | +15 | 현재가 > VWAP |
| VWAP 아래 | 0 | — |

**최대 이론값**: 15+25+20+15+15 = **90점**

### 1.2 등급 컷오프 (2026-02-10 상향)

| 등급 | 기준 | 비중 | 의미 |
|------|------|------|------|
| **A급** | ≥ 80점 | 100% | 최고 품질 |
| **B급** | 50~79점 | ~50% | 중간 품질 |
| **C급** | < 50점 | 0% | 진입 금지 |

### 1.3 전형적인 A급 조합

```
HTF(+15) + Sweep 방향일치(+25) + 강한OB(+20) + VWAP위(+15) = 75점 → B급
HTF(+15) + Sweep(+25) + 강한OB(+20) + 변동성수축(+15) + VWAP위(+15) = 90점 → A급
```

즉 A급 최소 조건 80점을 맞추려면: HTF+Sweep+OB+변동성수축 또는 HTF+Sweep+OB+VWAP 조합이 필요.

## 3. 가설 2 검증 — "A/B/C 등급이 실제 기대값을 분리하지 못하고 있다"

### A가 실제로 B보다 확실히 좋은가?

**Yes** — A(PF=0.682) > B(PF=0). 등급 구분력은 있다.  
그러나 A도 PF=0.682로 < 1.0이다. 수익 구조가 아님.

### B급 진입이 실질적 가치가 있는가?

**No** — B급 4건 WR=0%, PF=0.  
B급 4건 모두: Hard Stop 3건 + EF 1건. 전량 손실.  
B급 진입 사이즈는 A급의 ~50%인데, 이 50% 사이즈도 전부 손실이다.

### A급 중에도 실패 거래의 공통 패턴이 있는가?

**Yes — 시장 레짐**이 유일한 분리 기준이었다:

| A급 세부 분류 | 건수 | WR | 시장 환경 |
|--------------|------|----|----|
| 2026-01 진입 A급 | 4 | **100%** | KOSPI 강세 |
| 2026-02 진입 A급 | 11 | **9%** | KOSPI 하락 |

동일한 A급 신호가 시장에 따라 완전히 다른 결과를 냈다.

## 4. 재교정안 결정

### 검토한 두 가지 안

#### 안 1 — 현 구조 유지 + 가중치 조정

점수 항목 조정:
- Sweep 방향일치: 25→30점으로 상향
- VWAP 위: 15→20점으로 상향
- HTF: 15→20점으로 상향
- 약한 OB: 10→5점으로 하향 (약한 OB 과도 반영)
- A급 기준: 80→90점으로 상향 (더 엄격하게)

**효과**: 더 까다로운 A급 기준으로 신호 품질 향상  
**한계**: 시장 레짐 문제를 해결하지 않음 — 2026-02 같은 상황에서 여전히 실패

#### 안 2 — 시장 레짐 통합 (권장안)

등급 체계에 시장 레짐을 0번째 게이트로 추가:

```
새 등급 결정 흐름:
  Step 0 (새로 추가):
    시장 레짐 체크 → BEAR/SIDEWAYS → 사이즈 강제 축소 or 차단
  
  Step 1 (기존):
    CHoCH 점수 계산 → A/B/C 등급
  
  Step 2 (기존):
    B급 → 사이즈 × 0.5
    C급 → 진입 차단
```

시장 레짐 판단 기준 (기존 `market_context.py`에 있으나 등급과 미연결):
- KOSPI/KOSDAQ 5일선 > 20일선: BULL
- KOSPI/KOSDAQ 5일선 < 20일선: BEAR
- 그 외: SIDEWAYS

레짐별 사이즈 배율:
- BULL: × 1.0 (현재)
- SIDEWAYS: × 0.5
- BEAR: × 0.0 (진입 차단)

## 5. 권장안 — 안 2 채택

**"시장 레짐 0번째 게이트"를 CHoCH 등급 판단 이전에 삽입한다.**

### 구체적 구현 방향

**즉시 조치 (YAML 수정만, 코드 불필요)**:

```yaml
# config/strategy_hybrid.yaml
swing:
  # B급 진입 임시 비활성화
  min_choch_grade: 'A'   # 현재 'B' → 'A'로 변경
```

이 한 줄 변경으로:
- B급 4건처럼 WR=0% 진입을 차단
- A급(WR=33.3%)만 남겨 진입 품질 상승

**중기 조치 (코드 수정 필요)**:

1. `swing_runner.py`에서 매수 후보 선정 시 KOSPI MA5 vs MA20 체크
2. BEAR 판정 시 `ai_gate.min_score` 상향 (20→50) 또는 완전 차단
3. 결과를 `market_context` 테이블에 기록

### 기대 효과

| 지표 | 현재 | B급 차단 후 예상 |
|------|------|----------------|
| 진입 건수 | 113건 | ~109건 (B급 4건 제외) |
| WR | 23.9% | +1~2%p 예상 (B급 WR=0% 제거) |
| avg_pnl | -0.769% | 소폭 개선 예상 |
| 레짐 게이트 | 없음 | 하락장 진입 차단 → 대규모 손실 방지 |

### B급 비활성화가 완료 조건

B급 비활성화 후 30건 이상 거래 → 다음 항목 확인:
1. WR 개선 여부 (목표: 30% 이상)
2. ALPHA율 개선 여부 (목표: 20% 이상)
3. avg_pnl 양전환 여부
