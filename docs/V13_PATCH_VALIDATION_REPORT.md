## 5. 핵심 진단

### "손실은 줄었는가, 수익 기회는 유지됐는가?"

| 질문 | 답변 |
|------|------|
| EF/LCL이 최악 손실을 막았는가? | **부분 Yes** — EF avg -1.286% vs Hard Stop avg -2.815% |
| 패치 이후 승률이 올랐는가? | **No** — 25.6% → 9.1%로 하락 |
| 패치 이후 PF가 올랐는가? | **No** — 0.650 → 0.167로 악화 |
| 수익 확장 패치가 작동하고 있는가? | **No** — RAE/TED 미활성 |
| 시스템이 수익을 내고 있는가? | **No** — PF=0.407 |

### 근본 원인 진단

**현재 성과 악화의 주요 원인은 "필터 부족"이 아니라 "진입 신호 자체의 품질 저하"다.**

증거:
1. 조기(09:00~10:00) 진입 WR = 0% — 필터보다 먼저, 신호 자체가 틀림
2. time_exit(95건, 39%)이 가장 많음 — 포지션이 진입 방향으로 전혀 움직이지 않음
3. trailing에 도달한 33건만 수익 — 진입이 맞으면 trailing이 수익을 잘 잡음
4. EF 발동 후 WR 0% — EF로 잘린 것들이 실제 나쁜 진입이었음 확인

**문제의 본질**: 진입 신호의 방향성이 충분히 신뢰할 수 없는 상태.
