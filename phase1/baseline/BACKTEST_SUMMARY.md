1. **표본이 작다.** 41~81 거래. 부트스트랩 PF 95% 신뢰구간이
   A [0.98, 2.51] · B [0.47, 2.04] · C [1.11, 3.16] 로 **서로 크게 겹친다.**
   "A 가 B 보다 낫다" 는 이 데이터로 통계적으로 말할 수 없다.
2. **B 는 손익분기와 구분되지 않는다.** P(PF<1) = 44.5%.

   (`EXIT_PROFILE` 주석에 명시된 한계). 절대 수익률의 크기는 이 선택에 좌우된다.
   전 전략에 동일 적용되므로 **상대 비교는 유효**하다.
5. **유니버스가 고정 112종목이다.** 상장폐지·편입 변화가 반영돼 있지 않다
   (`phase1/SURVIVORSHIP_BIAS_REPORT.md`).

   백테스트 A 는 PF 1.56 이다. 원인 **확인 불가** (STRATEGY_COMPARISON §5).

## 4. 발견 — 8-1 에서 다뤄야 할 것

### 4-1. A 의 병목은 신호가 아니라 슬롯이다

```
A  신호일 792 → 슬롯 3개 → 체결 81 → 646건 폐기 (81.6%)
   후보가 빈 슬롯보다 많았던 날(binding) 126일 / 243일
```

**절반이 넘는 날에 "무엇을 고를지" 가 성과를 결정했다.**
진입 규칙을 바꾸는 것보다 **선별 규칙(ScoreEngine 순위)** 이 지렛대가 크다.
Phase 0.1 에서 이미 Top3/Top5/Random5 를 비교한 바 있으니 그 결과와 이어붙일 수 있다.

### 4-2. CHoCH 채택 근거가 재현되지 않는다

`swing_runner._entry_engine` docstring 은 `choch PF 1.639 / pullback PF 1.126` 로
CHoCH 우위를 기록하고 있으나, 이번 baseline 은 `choch 1.06 / pullback 1.56` 으로
**우열이 뒤집힌다.** 데이터셋·기간이 달라 어느 쪽이 틀렸다고 단정할 수 없다.

→ **feature flag 기본값 `pullback` 유지가 맞다.**
→ 8-1 에서 같은 유니버스·기간으로 재현 확인이 필요하다.

### 4-3. B 는 표본이 안 모인다

112종목 중 43종목에서만 신호가 나고 월 3.54건이다.
지금 빈도로는 E2(30건+) 급 증거를 모으는 데만 8~9개월이 걸린다.
