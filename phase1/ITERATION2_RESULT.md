### Experiment 2 — Live Gate

ON/OFF 재실행은 **불가능**하다. 차단된 신호의 반사실(counterfactual)
성과가 기록돼 있지 않아 "그때 진입했다면" 을 계산할 수 없다.
관측된 차단 분포만 남긴다.

```
blocked_trades        128 행
signal_rejections  47,796 행

상위 사유
  SMC: 구조 변화 없음                    10,158
  [ORPHAN_HALT] 고아 포지션               7,220
  [EC_HALT] dd=-54.4% ≤ -18%             3,737
  [EC_HALT] dd=-93.7% ≤ -18%             2,607
  [DD_HALT] 당일 PnL=-5.08%               1,388
```

**⚠️ EC_HALT 의 dd 값이 −54.4% · −93.7% 로 기록돼 있다.** equity
drawdown 93.7%는 정상 범위가 아니다 — 알려진 EC_HALT peak 오염 버그의
잔재로 보인다. 별도 확인이 필요하다.

## 결론

**백테스트와 실거래는 같은 전략의 실행 편차가 아니라 서로 다른
전략이다.**

- 다른 종목을 거래한다 (교집합 4.3%)
- 다른 기간을 보유한다 (17배)
- 다른 규칙으로 청산한다 (공통 사유 0종)

따라서 **백테스트에서 PF를 개선해도 실거래로 옮겨가지 않는다.**
Phase 0 ~ Phase 1 Iteration 1에서 수행한 모든 최적화 — Score Ranking,
Candidate Generator, Entry Filter — 는 실거래와 무관한 시스템을
튜닝한 것이었다.

이것이 Phase 1의 가장 중요한 발견이다.
